# cubeRotation

## Описание проекта
**cubeRotation** – небольшое консольное приложение на C++, демонстрирующее вращение трехмерного куба вокруг осей **X** и **Y** (с возможностью вращения и вокруг оси **Z**). Рендеринг осуществляется в текстовом режиме с помощью буфера символов, что позволяет запускать программу в любой консоли без графических библиотек.

## Основные возможности
- Вращение куба в реальном времени вокруг трех осей.
- Параметры камеры: поле зрения (FOV) и дистанция от наблюдателя.
- Кроссплатформенный код (поддержка Windows и POSIX‑систем).
- Полностью построено на стандартной библиотеке C++ (no external dependencies).

## Демонстрация
```
$ ./cube.exe
```
После запуска в консоли появляется анимированный куб, который плавно вращается.  
*(Для Windows используется `system("cls")`, для Linux/macOS – ANSI‑последовательности.)*

## Требования
- **Microsoft Visual Studio 2022** (или более новая версия) с установленным набором инструментов **v143**.
- Поддержка C++17 (по умолчанию в VS2022).
- Для сборки под Linux/macOS нужен компилятор **g++**/ **clang++** с поддержкой C++17.

## Сборка

### Windows (Visual Studio)

1. Откройте `cubeRotation.sln` в Visual Studio.
2. Выберите конфигурацию **Debug**/**Release** и платформу **x64** (или **Win32**).
3. Нажмите **Build → Build Solution** (Ctrl+Shift+B).  
   После успешной сборки исполняемый файл будет находиться в  
   `cube\Debug\` или `cube\Release\`.

### Linux / macOS (командная строка)

```bash
# Клонируем репозиторий
git clone https://github.com/yourname/cubeRotation.git
cd cubeRotation/cube

# Сборка с помощью g++
g++ -std=c++17 -O2 -Wall -Wextra -o cube main.cpp -pthread
# Запуск
./cube
```

> **Важно:** При сборке под POSIX‑системы необходимо добавить `-pthread`, так как в коде используется `std::thread`.

## Использование

Просто запустите полученный исполняемый файл. По умолчанию куб вращается автоматически. В коде `main.cpp` можно изменить параметры:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `WIDTH`  | Ширина буфера (символов) | 80 |
| `HEIGHT` | Высота буфера (строк)   | 40 |
| `FOV`    | Угол обзора (радианы)   | π/4 |
| `Z_DIST` | Дистанция камеры от куба| 5.0f |

Для изменения скорости вращения отредактируйте переменные `angleX`, `angleY`, `angleZ` в функции `main`.

## Как работает рендеринг

1. **Проекция** – функция `project` преобразует 3D‑координаты вершины куба в 2D‑координаты экрана, учитывая текущие углы вращения.
2. **Буфер экрана** – класс `ScreenBuffer` хранит двумерный массив символов, очищается каждый кадр и выводится в консоль.
3. **Главный цикл** – в `main` происходит:
   - обновление углов вращения,
   - проекция всех 8 вершин куба,
   - отрисовка ребер (в данном упрощённом примере – только точки),
   - вывод буфера и небольшая задержка (`std::this_thread::sleep_for`).
